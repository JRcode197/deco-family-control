Diagnostica Deco X50

Per la libreria API locale, prova admin come utente (non il nome personale). Usa la password del TP-Link ID proprietario del Deco: non quella del Wi-Fi né quella della dashboard. Verifica prima che la password funzioni nell'interfaccia web su 192.168.21.1. Non ripetere molti tentativi se il router rifiuta l'accesso. I dati valgono solo per questa prova; puoi condividere soltanto il risultato JSON.
